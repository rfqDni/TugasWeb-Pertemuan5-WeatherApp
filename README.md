# 🌤️ Weather App — Tugas Rutin 5

Aplikasi cuaca sederhana yang dibangun menggunakan **JavaScript Modern (ES6+)** dan **OpenWeatherMap API**. Aplikasi ini memungkinkan pengguna untuk mencari informasi cuaca terkini berdasarkan nama kota.

## 📋 Deskripsi

Weather App ini dibuat untuk memenuhi **Tugas Rutin 5** pada mata kuliah **Pemrograman Web**. Aplikasi menerapkan konsep-konsep JavaScript modern seperti `const`, arrow functions, template literals, `async/await`, Fetch API, serta manipulasi DOM dan error handling yang lengkap.

## ✨ Fitur

- 🔍 **Pencarian Cuaca** — Cari cuaca berdasarkan nama kota.
- 🌡️ **Informasi Lengkap** — Menampilkan nama kota, suhu (°C), deskripsi cuaca, ikon cuaca, dan kelembaban.
- ⏳ **Loading State** — Indikator loading saat proses fetch data berlangsung.
- ❌ **Error Handling** — Menangani error kota tidak ditemukan (404) dan network error.
- 📱 **Responsif** — Tampilan mobile-friendly menggunakan CSS Flexbox dan media queries.
- ⚡ **ES6+** — Menggunakan fitur JavaScript modern (const, arrow functions, template literals, async/await, array method).

## 🛠️ Teknologi yang Digunakan

| Teknologi | Keterangan |
|-----------|------------|
| HTML5 | Struktur halaman |
| CSS3 | Styling & responsif |
| JavaScript (ES6+) | Logika aplikasi |
| Fetch API | Komunikasi dengan API |
| OpenWeatherMap API | Sumber data cuaca |
